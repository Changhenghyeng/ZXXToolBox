# 通用桌面工具

此模块独立于 Unity 编辑器工具、Runtime 和 Shaders。目录名末尾的 `~` 用于让 Unity 忽略该目录，避免 Windows Forms C# 源码进入 Unity 编译。请保留这个名称；可将整个目录复制到 Unity 工程外单独使用。

| 工具 | 功能 | 源码与运行说明 |
|---|---|---|
| AI 图片工作室 | 模型选择、文生图/参考图、本地生成历史、Host 选择；含网页服务端和 Chrome 桌面启动器 | [AIImageStudio](AIImageStudio/README.md) |
| 应用联网控制 | 多应用分组、关联进程扫描、同路径同步限制、规则状态、托盘和自启 | [AppNetworkControl](AppNetworkControl/README.md) |
| 素材搜图 | 本地/共享素材库索引、截图框选检索、PSD/PSB 预览、数据迁移及便携打包 | [AssetSearch](AssetSearch/README.md) |

## 同步范围

收录源码、界面 HTML、模型目录、构建脚本、依赖声明、测试代码及第三方许可文本。不收录 EXE、DLL、历史版本、个人生成图片/参考图、浏览器资料、API Key、日志、索引和本机设置。

源码来源为本机 tools 目录的 2026-11-16 快照。[来源清单](SOURCE_INDEX.md)记录逐文件路径和 SHA256；后续更新以源码内容为准，分别核对各工具当前源码，不把历史产物版本直接当源码版本。源码目录与本机成品的版本标识存在差异，见各工具说明。

仓库整体版本为 v0.9.0，各应用原有版本号独立保留。Unity 模块继续沿用原有位置，本次未同步 Unity 源码。构建步骤用于开发者从源码生成程序，本次不是已运行验证的二进制发布。
