应用联网控制 v1.1.1 — 自适应界面版

使用方法
1. 双击 tools 根目录的“启动应用断网.cmd”，按系统提示允许管理员权限。
2. 点击“添加 EXE…”，可同时选择多个 EXE 或普通 .lnk 快捷方式。每个目标独立显示一组。
3. 启动并使用目标软件，工具每 5 秒扫描一次关联进程并补充列表。
4. 勾选某行立即为该 EXE 创建入站和出站禁网规则；取消勾选立即删除本工具针对该路径的规则。
5. 相同完整路径的 EXE 在所有组中自动同步勾选，只需操作一次。同名但路径不同则分别控制。

默认行为
- 新添加的主程序及新发现的关联程序默认不勾选。若该路径已在其他组被勾选，则自动同步已有状态。
- 每一组都会持续扫描；扫描本身不会把未勾选的程序自动禁网。
- 关联程序识别沿用原版：当前仍运行、属于主程序后代进程且出现在 TCP/UDP 表中的程序。
- 扫描会保留已发现的程序和手动选择。未运行的项目仍保留，可以提前设置禁网。
- 所有目标共用一次进程树及网络表读取，避免每组重复扫描整台电脑。
- 点击关闭或最小化会进入托盘；从托盘菜单退出才会结束程序。退出后禁网规则仍有效。
- 移除选中组会解除仅属于此组的程序的本工具限制；其他组共用的程序不变。

状态与性能
- 每 30 秒读取一次本工具规则及当前 Windows 防火墙启用状态。
- “已禁网（规则有效）”表示规则检查通过，不是实际网络请求测试。真实验证请重启目标软件并执行联网操作。
- “未限制”只表示本工具未阻止该路径，不保证其他防火墙、安全软件或网络设置没有限制。
- 外部删除/禁用规则后会显示异常，工具不会悄悄改动 Windows 防火墙总开关。重新勾选可重建本工具规则。
- 底部显示本工具 CPU（占全机 CPU 的比例）、内存工作集、上次扫描及规则检查的耗时；每 2 秒刷新。
- 这些指标不包含 Windows 防火墙服务本身的资源消耗。
- 定时扫描不是无遗漏的进程追踪，短暂进程可能错过；未勾选的新进程不会被自动拦截。

配置与升级
- 新版配置：%LOCALAPPDATA%\应用联网控制\groups-v2.json。
- 首次运行导入旧版 history.json 的名单，并依据现有本工具防火墙规则恢复勾选；不覆盖旧版历史文件。
- 后续从新版配置恢复所有组及勾选状态。
- 已启用开机自启时，新版启动会将同名自启任务更新到当前 EXE；未启用则不创建任务。
- 请勿同时运行新旧两个版本。旧版不认识新版分组状态；回退后操作共用 EXE 时，应重新核对规则。
- 程序需要管理员权限；不安装额外驱动。成品为 64 位 Windows 10/11 自包含程序。

v1.1.0 更新
- 单目标界面改为多个展开的应用组；支持一次添加多个程序。
- 勾选即时应用，移除原“禁止联网 / 恢复联网 / 开始监控 / 验证”按钮。
- 同路径全局同步；取消时清除该路径在旧版各组下遗留的本工具规则。
- 自动扫描、定期规则检查、实时资源状态栏、托盘与开机自启。
- 独立新版配置，保留旧数据文件及旧版发布包。
