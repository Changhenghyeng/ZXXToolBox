# BIGBRO 工具集使用说明

> 本文档面向美术同学，用通俗的语言解释每个工具是干什么的、怎么用。

---

## 如何打开工具

所有工具都通过 **BIGBRO ToolBox（工具箱面板）** 统一入口打开：
1. 点击 Unity 顶部菜单 **ArtTools → BIGBRO ToolBox**
2. 在弹出面板中，顶部有分类标签：**场景搭建 / 资源制作 / 视觉烘焙 / 批量操作 / 检查与输出**
3. 点击对应工具卡片即可打开

> 部分常用工具也有独立快捷键，见下方各工具说明。

## 一、场景搭建

### 1. ProcGen — 程序化生成（在模型表面自动种东西）
**用途：** 在选定的 3D 模型表面，按你设定的规则自动散布预制体（比如在大地形上种树、放石头、摆装饰物）。

**怎么用：**
1. 打开工具，在 "Target" 拖入你要在上面放东西的模型（必须有 Mesh）
2. 设置全局参数：网格间距（Cell Size）、随机程度（Jitter）、散布方式（均匀/随机/扎堆）
3. 在 Slot（插槽）列表里添加要散布的 Prefab，设置数量、大小范围、最小间距
4. 可以添加多个 Slot，设置优先级（数字越小越先生成，高优先级可以挤掉低优先级的）
5. 点击 **Generate** 生成
6. 生成的物体会放在 `[ProcGen Root]` 节点下，可以用 Ctrl+Z 撤销

**小贴士：**
- Spread Bias = 0 是均匀散开，0.5 是随机，1 是抱团
- 可以勾选调试可视化，在 Scene 视图里看到候选点和碰撞盒
- 每次生成会创建独立的 Root 节点，新批次自动避让旧批次

---

### 2. Path Builder — 路径生成

**用途：** 沿路径生成墙体、山脉散布和可变宽河流，也支持围墙、L 型墙角、走廊和单排直线排列。

**怎么用：**
1. 选择模式：
   - **Enclosure（围合）**：四面围墙，可选四角转角 Prefab
   - **LShape（L 型）**：两面墙
   - **Corridor（走廊）**：两条平行墙壁
   - **Line（线性队列）**：沿 X/Y/Z 轴等距排列
2. 拖入墙段 Prefab（围合模式还可以拖入转角 Prefab）
3. 设置长边长度、宽边长度、每段个数（或开启自动计算）
4. 点击 **Build Walls**（或 Build Queue）
5. 生成的墙体会放在一个新根节点下

**小贴士：**
- Face Inward（朝内）勾选后墙壁会面向内部
- 支持 Ctrl+Z 撤销整组

---

### 3. Fog Of War Tool — 战争迷雾网格

**用途：** 为 SLG 场景生成一张可点击的战争迷雾遮罩面片。玩家点击面片上的格子可以"探索"迷雾。

**怎么用：**
1. **设置区域**：选中场景中要覆盖的物体，点击 **Fit To Selection Top View** 自动计算范围（或手动输入 Origin 和 Size）
2. **设置网格**：填入列数（Columns）和行数（Rows），选择迷雾颜色
3. **创建**：点击 **Create Clickable Fog Grid**，会在场景中生成 Fog Grid Click System
4. **操作已生成的网格**：选中生成的网格对象后，可以用 Hide All / Show All / Reset Mask 等按钮控制

**小贴士：**
- Force Square Cells 开启后强制每个格子为正方形
- 可以导出当前 Mask 为 PNG 图片
- 调试网格线可以切换显示/隐藏

---

### 4. Day Change Transition — 昼夜过渡

**用途：** 一键搭建 SLG 的短昼夜过渡系统：白天→黄昏→夜晚→白天。灯光和后处理在过渡期间自动变化，结束后还原。

**怎么用：**
1. 打开工具，指定主光源（点击 **Auto** 自动查找场景中最亮的方向光）
2. 调整时间参数：
   - **Fade To Night**：白天过渡到夜晚的时长（秒）
   - **Night Hold**：夜晚停留时间（0=不停留，负数=永久停在夜晚）
   - **Fade To Day**：夜晚恢复白天的时长
3. 点击绿色按钮 **Create / Repair Setup** 一键创建场景中的 Controller 和 Volume
4. 在 Preview 区域可以预览 Day / Dusk / Night 状态，或播放完整过渡动画
5. （可选）在 Material Transitions 区域添加材质属性过渡

**小贴士：**
- 运行模式下点击 **Trigger Transition** 才能真正触发
- Scrub 滑块可以在编辑器中手动拖动预览进度

## 二、资源制作

### 5. Building Card Prefab — 建筑面片生成

**用途：** 把建筑的正交渲染 PNG 图片一键生成带碰撞体的面片预制体（用于 SLG 建筑）。

**怎么用：**
1. **设置参数**：
   - 拖入参考用的正交相机（Reference Camera）
   - 设置 Cell Size（一个格子的世界边长，单位米）
   - 设置 Output Folder（输出到哪里）
2. **导入图片**：把建筑 PNG 拖入窗口或点 Add Selected
3. **设置占格**：在列表中填写 Grid W×D（建筑占几格宽×几格深）
4. **检查预览**：右侧预览中可以看到自动分析的地面标注点，如果不对可以手动拖动四个角点
5. **点击 Generate**：生成预制体、材质和 Mesh

**输出的预制体结构：**
- 根节点：带 BoxCollider（碰撞盒），原点在地面对角线交点
- Visual 子节点：带 MeshRenderer 的面片

**小贴士：**
- Body Alpha 阈值决定哪些像素算"建筑实体"（高 Alpha），哪些算阴影（低 Alpha）
- Ground Margin 可以等比缩小面片，让碰撞盒比画面略小
- 可以在 Atlas 面板把多个建筑合成到一张图集上减少 DrawCall

---

### 6. Box Collider Generator — 批量生成碰撞盒

**用途：** 批量为多个预制体自动计算并添加 BoxCollider。

**怎么用：**
1. 从 Project 窗口选中预制体，点 **Import From Selection** 导入
2. 为每个预制体选一个挂点（Mount，碰撞盒挂哪个节点）和参与节点（哪些子节点参与包围盒计算）
3. 设置选项：已有碰撞盒是覆盖还是跳过、是否设为 Trigger
4. 点 **Generate Preview** 预览写入计划
5. 确认无误后点 **Confirm Write** 写入

**小贴士：**
- 支持回滚：写入前会自动备份，可以从备份恢复
- 可以选择复制第一个预制体的选择到所有预制体
- 碰撞盒会自动扩展 0.5% 边距防止太紧

---

### 7. Convert Variant To Normal Prefab — 变体转普通预制体


**用途：** 把 Prefab Variant（预制体变体）转换成独立的普通 Prefab，彻底断开与原模板的继承关系。

**怎么用：**
1. 在 Project 窗口中选中一个或多个 Prefab Variant 文件
2. 在工具箱中点击 **Convert Variant To Normal Prefab**
3. 工具自动处理，完成后弹窗报告结果

**适用场景：** 当你确定变体不再需要跟随原模板修改时使用。

---

### 8. Prefab Extractor — 预制体提取工具

**用途：** 从大型预制体中提取重复出现的子结构，生成共享的子预制体，实现模型复用。

**怎么用：**
1. 把要分析的大预制体拖入 Source Prefabs 列表
2. 设置输出目录（Output Root Folder）
3. 设置最小共用次数（Min Share Count，出现多少次才提取）
4. 点击 **Analyze** 分析
5. 查看分析预览，确认要提取的共享组
6. 取消 Dry Run 后点击 **Execute** 执行提取

**小贴士：**
- Mesh Nodes Only：只提取含 Mesh 的节点
- Loose Matching：宽松匹配模式，只按 Mesh 路径匹配
- Auto Backup：执行前自动备份原预制体

---

### 9. Normalize Prefab Root — 规范化根节点

**用途：** 把预制体根节点的 Transform 归零（Position 0,0,0 / Rotation 0,0,0 / Scale 1,1,1），把原来的位移和旋转保留到 `_Content` 子节点上。

**怎么用：**
- **快捷键 Ctrl+Shift+N** — 在 Hierarchy 中选中物体后直接按
- 或右键菜单 **GameObject → Normalize Prefab Root**
- 也可以在工具箱中点击 **Normalize Prefab Root** 打开面板操作

**小贴士：**
- 如果物体已经被规范化过，再次执行会做原位烘焙（Bake）
- 处理后根节点永远是干净的 identity，方便程序代码挂载

---

### 10. Prefab Name Sync — 同步预制体名称


（在工具箱中显示为 "Sync Names"）

**用途：** 把场景中 Prefab 实例的名字恢复为 Prefab 源资源的名字。

**怎么用：**
- **有选中物体**：只处理选中的物体及其子物体
- **无选中物体**：弹窗确认后处理整个场景
- 在工具箱「批量操作」分类下点击 **Sync Names**

---

## 三、视觉烘焙

### 11. Shadow Baker — 建筑阴影烘焙 + 地面贴花

**用途：** 给建筑生成俯视投影阴影贴图，并在脚下放一个地面贴花面片，让建筑看起来有"落地感"。

**怎么用：**
1. **添加目标**：把要烘焙的建筑拖入列表（或从选中填入）
2. **设置光源**：指定光照方向（手动拖 Directional Light，或输入角度/方向向量）
3. **烘焙参数**：设置分辨率、柔边模式（高斯模糊/距离场）、偏移留白
4. **贴花输出**：选择贴花 Shader 类型、阴影颜色、Y 偏移
5. **输出路径**：设置阴影贴图和贴花预制体的输出目录
6. 点击 **Bake + Generate** 执行

**小贴士：**
- 贴花默认挂在建筑下方，也可以选择不挂载
- 可以开启"烘焙后关闭 Cast Shadows"

---

### 12. Self Shadow Baker — 自阴影烘焙

**用途：** 把固定方向的自阴影和 AO（环境光遮蔽）烘焙到模型的 UV2 贴图里，运行时着色器自动读取，让模型在没有实时光影的情况下也有立体感。

**怎么用：**
1. 从 Hierarchy 选中要烘焙的模型，点 **Add Selected** 填入
2. 检查 Lightmap UV（如果不是 Unwrapped 会提示修复）
3. 选择光源方向（四种方式：场景主光 / 手动拖 Light / 输入角度 / 输入方向向量）
4. 设置烘焙参数：
   - **自阴影（R 通道）**：分辨率、阴影贴图大小、软阴影 PCF 参数
   - **AO（G 通道）**：采样数、最大距离、对比度
   - **补光（B 通道）**：暗部反光方向
5. 点击 **Bake R+G+B All** 一次性烘焙三个通道
6. 结果输出到 Output 目录，预览面板可以查看缩略图

**小贴士：**
- 可以分别烘焙 R/G/B 通道，互不覆盖
- 输出贴图的 sRGB 是关闭的（存的是线性数据）
- 在 Scene 视图中可以看到黄色光照方向箭头

---

### 13. Outline — 外描边烘焙

**用途：** 给角色/模型的 Mesh 生成平滑法线存入 UV2，配合 `Custom/ToonOutline` Shader 实现卡通外描边效果。**不修改原始 FBX 文件。**

**怎么用：**
1. 拖入 Target 目标物体（Prefab 或场景中的 GameObject）
2. （可选）拖入 Outline 材质球
3. （可选）设置 Output Path 输出目录
4. 点击 **Bake** 烘焙平滑法线到 UV2
5. 点击 **Add Material** 给所有 Renderer 添加 Outline 材质
6. 如果不满意，点 **Clear** 恢复为原始 Mesh

**小贴士：**
- 重复 Bake 会覆盖旧的烘焙文件，不会产生垃圾
- Clear 会删除所有 `_baked.mesh` 烘焙文件并还原

---

### 14. Shading Mode — 软硬边切换预览

**用途：** 非破坏性地预览模型的软边（平滑着色）和硬边（平面着色）效果，方便检查模型法线是否正常。**不会修改原始 Mesh 文件。**

**怎么用：**
1. 在 Hierarchy 中选中要检查的模型
2. 打开工具，点击 **Capture Selected Meshes** 捕获模型
3. 用滑块或预设按钮调节平滑度（0% = 硬边，100% = 软边）
4. 可以统一调节所有模型，也可以每个模型单独调
5. 检查完后点击 **Restore All** 恢复

**小贴士：**
- 同时支持 MeshFilter 和 SkinnedMeshRenderer
- 相同的 Mesh 会复用计算结果，节省内存

---

### 15. Light Cookie Scroller — 灯光 Cookie 滚动


**用途：** 给场景中的灯光添加 Cookie 纹理滚动动画（比如云影流动、焦散光斑、水面光波）。

**怎么用：**
1. 在 Hierarchy 中选中要添加效果的灯光
2. 在工具箱中点击 **Light Cookie Scroller**

## 四、批量操作

### 16. Batch Replacer — 批量替换

**用途：** 在 Hierarchy 中一次把多个旧物体替换成新物体（预制体/模型/场景物体），同时保留位置、旋转、缩放。

**怎么用：**
1. 在 Hierarchy 中多选要替换的物体
2. 打开工具，在 Target 字段拖入新物体（预制体或场景物体）
3. 根据需要勾选保留项：名称、旋转、缩放、Layer/Tag、材质
4. 点击 **Replace** 执行替换

**小贴士：**
- 支持 Ctrl+Z 撤销
- 替换完成后自动选中所有新物体

---

### 17. Batch Rename Tool — 批量重命名

**用途：** 对 Project 或 Hierarchy 中的大量资源按规则批量重命名。

**怎么用：**
1. **选择来源**：
   - Project Selection：用 Project 窗口当前选中的
   - Project Folder：选文件夹
   - Hierarchy Selection：用 Hierarchy 选中的
   - Prefab Dependencies：收集 Prefab 的所有依赖资源
2. **设置规则**：字符串替换、前缀/后缀、删除首尾字符、自动编号等
3. **点击 Analyze Preview** 查看预览（原名→新名）
4. **点击 Execute Rename** 执行（不可撤销，建议先提交版本控制！）

**小贴士：**
- Prefab 依赖模式很强大：可以按 Prefab 名 + 类型前缀批量给贴图/模型/材质重命名
- 贴图槽位智能识别：`_MainTex` → `_BC`，`_BumpMap` → `_N` 等
- **执行前一定要提交 Git/SVN**

---

### 18. Cast Shadows OFF — 关闭阴影投射


**用途：** 一键关闭选中物体（含所有子物体）的 Cast Shadows（阴影投射）。

**怎么用：**
- 在 Hierarchy 中选中物体，在工具箱点击 **Cast Shadows OFF**
- 如果没有选中，会弹窗确认后关闭整个场景所有物体的阴影投射

## 五、检查与输出

### 20. Transparent Screenshot — 透明背景截图

**用途：** 截取 Game 视图画面并输出为带透明背景的 PNG。支持普通截图、动画序列帧、粒子特效序列帧。

**快捷键：Ctrl+Shift+X**（快速截图，不需要打开窗口）

**怎么用：**
1. 打开工具（**Tools → Transparent Screenshot Window**）
2. 选择目标 Camera
3. 设置输出宽高、Super Size（超采样倍数）、输出文件夹
4. 选择模式：
   - **Single**：单帧截图
   - **Anim Seq**：动画序列帧，指定 AnimationClip 和目标，输出拼成一张大图
   - **Particle**：粒子序列，拖入粒子根节点，设置时长和 FPS
5. 点击 **Capture** 截图

**小贴士：**
- 透明背景是通过"双背景抠图算法"实现的，支持后处理 + 半透明
- Shadow Catcher 模式可以只保留物体和影子，地面变透明
- Super Size = 2 时输出分辨率是设置值的 2 倍

---

### 21. Label Tool — 场景标签显示

**用途：** 在 Scene 视图中自动显示场景物体的名称标签，方便在复杂场景中定位物体。

**怎么用：**
1. 打开工具，设置扫描范围（拖入根节点或留空扫描整个场景）
2. 点击 **Scan** 扫描场景中的物体
3. 标签立即显示在 Scene 视图中
4. 可以调整样式（底板颜色/圆角/描边、字体/字号/颜色）
5. （可选）点击 **Bake** 把标签烘培成静态 TextMeshPro 对象，发给没有装工具的同事也能看到

**小贴士：**
- Use Prefab Name 开启后用 Prefab 源名字而不是场景实例名字
- 可以给特定 Prefab 设置别名
- LOD 设置可以控制标签在什么距离内显示

---

### 22. Measure Tool — 三维测量

**用途：** 在 Scene 视图中测量物体的尺寸和距离。

**两种模式：**
- **Bounding Box（包围盒）**：选中物体，显示宽(X)、高(Y)、深(Z) 以及体积
- **Ruler（标尺）**：在 Scene 视图中点击放置起点，再点击放置终点，显示直线距离和 X/Y/Z 三轴分量

**怎么用：**
- 包围盒模式：点击 **Add Selected** 添加要测量的物体，Scene 视图实时显示包围盒
- 标尺模式：切换到 Ruler，在 Scene 视图中点击放起点→移动鼠标看预览→再点击放终点
- 单位可切换为米/厘米/毫米

**小贴士：**
- 标尺模式下按住 **V 键**可以启用顶点吸附
- 按 **Esc** 清除当前测量

---

### 23. Git Path Navigator — Git 路径定位

**用途：** 粘贴 Git 路径（比如从 Git diff 或命令行复制来的文件路径），自动在 Project 窗口中定位到对应资源。

**快捷键：Ctrl+G**

**怎么用：**
1. 按 Ctrl+G 打开窗口
2. 粘贴包含 `Assets/...` 的路径
3. 工具自动提取资源路径并在 Project 窗口中高亮定位
4. 可以点 **Reveal in Explorer** 在系统文件管理器中打开

**小贴士：**
- 支持模糊匹配，路径不完全精确也能找到
- 历史记录会保存最近 50 条路径，可按日期筛选

## 工具箱编辑模式

在 BIGBRO ToolBox 面板中点击齿轮图标 ⚙ 进入编辑模式，你可以：
- 修改工具箱面板的名称（会同步到菜单）
- 用 ▲▼ 拖拽调整工具排序
- 修改每个工具的描述文字
- 隐藏不常用的工具
- 调整工具所属分类

修改完成后点击"保存并退出"，设置会存入配置文件，团队共享。
